# 第二关 · 主题锚定自检

[返回首页](../README.md) · [写作总调度](paper-orchestrator.md) · 脚本：`scripts/gates.py`

**目标：让每一句话回头对一遍全文核心主旨，别写着写着跑偏。**

先打个比方。

**像开车看导航。** 你可以每一段路都开得很稳，但如果某一公里方向偏了 5 度，开到最后会离目的地很远，而且**中途看不出问题**。论文也是：结果段罗列数据、结论段扯到别的事，单看每句话都没错，合起来就散了。

这一关就是**每隔一段就校对一次方向**。

---

## 一、为什么结果段和结论段最容易跑偏

- **结果段**：有一堆数字等着写，很容易变成数据台账，忘了"这些数字在回答什么"。
- **结论段**：写到这里容易发散——提到应用、提到未来、提到不相干的方法比较。

所以规范要求：**撰写结果、结论时不能单纯罗列数据和现象**。每一句都要能回答"这句话怎么服务于全文的核心研究目标"。

---

## 二、执行流程

### 1. 读取两个东西

- **全文核心主旨 + 核心科学问题**（写作前期录入，**作为永久参照基准，全程不变**）
- 当前待校验段落（重点：结果箱、结论箱；数据箱次之；引言箱按需）

### 2. 逐句自检，回答三个问题

| # | 问题 |
|---|---|
| ① | 这句话和全文核心主旨有没有**直接关联**？ |
| ② | 这句话能不能**支撑、佐证**本文的核心科学问题？ |
| ③ | 如果删掉这句话，会不会**影响核心论点的论证**？ |

### 3. 分类判定

| 判定 | 条件 | 动作 |
|---|---|---|
| ✅ **高度贴合** | 句子与核心主旨有共同锚点 | 进入下一关（靶心校验） |
| ⚠️ **弱关联** | 段落整体有关联，但这一句没有 | 标出来，给修改建议：**增加一句衔接**，说明该数据/现象如何支撑核心科学问题 |
| ❌ **完全脱离** | 整段与核心主旨无共同锚点 | **驳回重写**，剔除无关内容 |

---

## 三、脚本怎么算（以及它的上限）

锚点是**核心主旨与核心科学问题里的术语集合**。判定靠术语重合度：

```text
段落与核心主旨有共同术语        → pass
段落有共同术语，但某句没有      → flag（弱关联）
段落整体没有共同术语           → reject
```

**中文必须用 n-gram 才算得动。** 中文没有空格，如果把"一整串汉字"当成一个术语，它永远不可能和别的句子重合——第一版就踩了这个坑。现在把每个连续汉字串切成 2 字与 3 字片段作为术语，才有可比较性。

⚠️ **这是启发式初筛，不是语义判断。** 报告里固定写着 `heuristic_term_overlap`。"这句话有没有服务主旨"的最终判断仍在模型和人身上。**不要因为脚本说 pass，就认为这一段真的紧扣主旨。**

---

## 四、硬性约束

| # | 约束 |
|---|---|
| 1 | **不能修改红锁保护的数据、参数、观测事实**。只评估论述关联性、优化论述逻辑，不篡改实验结果 |
| 2 | **只做关联性判断，不凭空新增不存在的推论或科学结论** |
| 3 | **结果箱、结论箱必须强制启用**；数据箱建议启用；引言箱按需 |
| 4 | 每次自检输出简短主题锚定报告：匹配程度、识别到的脱离主题语句、修改建议 |

第 3 条的"强制启用"在实现里体现为：**结果/结论箱段落若与主旨无任何共同锚点，直接 reject**，不给"跳过"的余地。

---

## 五、输出

```json
{
  "gate": "topic_anchoring",
  "verdict": "reject",
  "report": "the paragraph shares no term with the core thesis; results and conclusions must serve the main line",
  "details": {
    "paragraph_anchors": ["中层温度", "扰动", "响应"],
    "supports_question": "中层温度在扰动期间的变化幅度是多少",
    "weak_sentences": ["…"],
    "off_topic_sentences": ["…"],
    "method": "heuristic_term_overlap (semantic judgement stays with the model)"
  }
}
```

**没有核心主旨时这一关不会通过。** 缺少 `core_thesis` / `core_questions` 会返回 `flag` 并写明 `cannot_check: true`——先补主旨，再写正文。

---

## 六、检查清单

- [ ] 全文核心主旨与核心科学问题已在写作前录入，且**全程没有变过**。
- [ ] 结果箱、结论箱的每段都跑过这一关。
- [ ] 弱关联句给出了"怎么建立关联"的具体建议，而不是只标了一个警告。
- [ ] 没有任何数据、参数、观测事实被这一关改动。
- [ ] 没有为了方便通过而新增原文不存在的推论。
