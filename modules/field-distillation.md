# 从领域资料提炼可执行知识

目标是“下一次遇到同类研究问题时知道何时采用何种方法”，不是论文摘要合集。

先为全文、仪器文档、代码建立目录、版本和来源清单。完整方法、公式或适用条件即使只出现在一处，也不能因没有重复出现而丢弃。文献结论、领域可复用规则、本项目发现分开存储。

每张能力卡包含：ID；触发任务；输入与单位；完整操作；参数由何处确定；输出；可执行验证；适用范围；反例/冲突；原文定位；证据等级；相邻方法的区别。规则状态使用 candidate / usable_within_scope / reference_only / unresolved。单次事件结果不升级为领域定律。

机制资料逐条区分 observed / statistical association / proposed explanation。存在不一致时比较仪器、高度、纬度、地方时、事件阶段、基线、样本与分析口径，不机械多数表决。只抽取来源足以支持的结论；推导注明它是当前分析的推导。

检验使用未参与提炼的材料。测试至少覆盖：换仪器/坐标、换事件基线、缺失风场、随机噪声与相关样本、资料矛盾、摘要不足、引用错配。对比通用提示词、通用母 Skill、领域包三个条件，记录真实输出差异，不凭感觉宣称性能提升。

本包的 domain.json 是接口和审查清单，不是已经从用户论文蒸馏完成的知识库。新增领域通过独立目录和相同接口替换；不写入固定个人画像或固定事件结果。
