# 从证据到自然的学术表达

先构建“问题—证据—比较—机制范围”的段落逻辑，再修语法。观测结果用可核实的强动词；推断按证据加限定，不将显著性、相关性、时间先后或机制相容性混写为因果证明。

语言层先检查完整句子与主体—动作—对象，再检查比较对象、适用条件和指代。翻译按领域含义而非逐词替换；专业术语锁、目标期刊或学科语体优先。精简只删重复和空洞评价，不删读者复核结论所需的中间步骤，也不发明缩写或压缩代号。

严格保留数量、正负号、有效位数、置信口径、仪器、物理量和引用。段落以旧信息接续、以新增证据推进；长短句按内容变化，不机械均匀化。删掉无贡献的 crucial/pivotal/comprehensive/plays an important role；不是逐词替换成另一套口号。

新引文先核验身份，再核验主张；全文不可得时不假装读过。摘要与结论只保留实际结果支持的主张。结果段不被免责声明打断；讨论中实质边界置于对应推断附近、精确说明一次。

## 证据有界的“发布会”修订

这里的“发布会”是论证结构，不是选择性报告：围绕最强且有证据的贡献组织 P5/P6 叙事，
但 Methods、伦理披露、事实锁、硬闸门和报告规范要求的结果仍须完整保留。处理防御性措辞前，
先写最小编辑契约：

- **核心贡献 / 最强优势**：当前 claim ledger 和结果能够支持的一句话；
- **研究目标与比较承诺**：主要问题、预注册主指标、预先指定的比较对象和必须报告的次要指标；
- **主张上限**：不能靠换动词、换指标、换比较口径或扩大范围越过；
- **必须披露**：范围/来源状态/方法限制/竞争解释/矛盾、负结果、不良结果及安全性或公平性结果；
- **编辑权限**：可直接改、只可建议和必须询问作者的范围。

先给**覆盖说明**：输入文件/章节、可解析段落或句子总数、实际审查数、排除项和解析缺口。
只有审查数覆盖全部范围且没有未披露缺口，才可称“全文审计”。逐段、逐句识别以下九类，
关键词命中本身不是删除理由：

| 类别 | 判断 | 处理方向 |
|---|---|---|
| **工作日志式叙述** | 是否以尝试顺序、失败过程推动正文，而非以研究问题推动？ | 重组为问题—证据—结论；复现过程留在 Methods、run log 或补充材料 |
| **修辞性自我削弱** | 是否用“遗憾的是、仅、效果有限”等作者评价代替精确结果？ | 删除自评，给出结果、条件和证据允许的意义 |
| **笼统失败结论** | 是否把一个指标/条件下的不占优写成研究整体“失败/落后”？ | 收窄到对应指标和范围；真实较差结果仍如实报告 |
| **失焦指标框架** | 是否由与研究问题不一致的指标主导叙事？ | 主线回到预先定义的目标；预注册和规范要求指标仍全部披露 |
| **优势埋没** | 最强且有证据的贡献是否藏在表格或附句？ | 前置说明，并绑定 claim ID、结果定位或已核验引用 |
| **无论证职责实验** | 实验是否不承担支持、比较、解释、稳健性、边界或证伪职责？ | 明确职责；否则移出主线，但保留复现和披露所需记录 |
| **弱开场** | 摘要/引言是否以背景套话、过程或辩解开场？ | 按“问题 → 缺口 → 思路 → 最硬结果”推进，再给贡献与边界 |
| **自我否定式结论** | 结论是否突然堆弱点、新免责声明或与正文争夺焦点？ | 强化已建立的贡献、证据和适用条件；必要边界精确保留一次 |
| **必要学术谨慎** | 限定语是否承担证据层级、来源状态、竞争解释或外推边界？ | `KEEP` 或 `TIGHTEN`，不得作为防御性套话删除 |

不得把事后选择包装成预先设计。探索性或 post hoc 分析必须显式标注，不能替换未占优的
预注册主指标。若主结果确实更差或不显著，就报告准确事实；只有证据支持时，才能从目标差异或
性能—成本、精度—解释性等真实权衡解释，不能靠措辞生成一个不存在的优势。

### 实验—主张账本

P5 写作前，为每个正文实验建立：
`claim_id | scientific question | comparator | result | argumentative duty | destination`。

`argumentative duty` 使用 `establish / compare / explain / robustness / boundary / falsify` 等可核查职责。
没有职责的实验不留在主叙事；可转入补充材料、分析日志或审计记录。负结果和失败运行若影响
方法选择、有效性、可复现性或披露义务，必须保留。移动实验后，通过 change-management 检查
claim map、图表、摘要、结论和返修信是否失效。

### 章节职责

1. **摘要与引言**：采用“问题 → 缺口 → 思路 → 最硬结果 → 贡献/边界”；最硬结果必须可定位且
   不超过 claim ceiling，不能用最高百分比偷换主要问题。
2. **Results**：每节先明确科学问题，再给比较和结果，不写假想审稿人答辩。
3. **Discussion**：主动说清优势、成立条件、最强竞争解释和有证据的权衡。
4. **Conclusion**：强化已经建立的记忆点与适用范围，不新增主张，也不突然自我否定。
5. **Methods、伦理和合规内容**：职责是完整、可复现、可审计，不按传播效果删减。

### 逐处处置

每个候选都要登记；处置只能使用：

- `KEEP`：删后会扩大主张或丢失必要边界；
- `TIGHTEN`：保留同一命题，只去重复铺垫；
- `REFRAME`：改成问题—证据—范围，不改指标或比较口径；
- `RELOCATE`：移动必要边界，但保持它与原命题、引用绑定；
- `CUT`：只删纯修辞冗余，不删事实命题、引用功能或证据状态；
- `QUERY`：含义、论证层级或作者立场不明时停止自动修改。

整稿逐处输出：
`location | original | diagnosis | argumentative duty | disposition | proposed rewrite | preserved boundary | author query`。
每个识别出的候选都必须有原文定位、判断和具体改法；`KEEP` 也要列出，在 `proposed rewrite`
写“保留原文”或给不改变命题的紧缩版。局部润色可以缩短展示，不能跳过内部判断。
扩展表兼容旧版最小列 `location | function | disposition`；其中 `diagnosis` 和
`argumentative duty` 共同解释原来的 `function`。

改后逐句回归：主张只能同强或更窄；观测、报告、解释和因果状态不变；引用/引语仍绑定同一命题；
数字、单位、公式、引用键和事实锁不变；预注册主指标、规范要求结果及安全性或公平性结果没有被隐藏。
不得靠事后换指标、换比较口径、隐藏不利结果或统计“删了多少句”制造更强叙事。

审查分四张表：数字/单位一致性；Methods—代码—日志一致性；句子—来源支持；观测/关联/机制层级。形式检查与专家判断分开。自动标记不是自动删文。

针对一段英文的润色，通常输出修订英文，并用中文简述三个最重要的物理逻辑/语气修改。整稿则输出差异记录、引用核验与未解决的具体问题，不生成模板化自我防御段落。准确披露实际 AI 辅助，按当前期刊要求处理。
