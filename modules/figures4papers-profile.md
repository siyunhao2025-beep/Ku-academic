## 优先级与追溯合同

本画像只控制表现层，优先级低于真实数据、统计定义、期刊规范、`modules/figures.md` 和 `scripts/figures.py`。任何样式建议与这些规则冲突时，以本地规则为准。

每张数据图必须留下可重跑链：

`source_data -> plot_script -> outputs -> caption_or_explanation`

四段都写入项目记录：原始或分析结果文件及其版本/哈希；实际运行的脚本、环境和参数；稳定文件名的矢量与预览输出；能独立解释数据口径、视觉编码和限制的图注。图注或 `figures/manifest.json` 还应记录轴范围、尺度变换、色条范围、掩膜、缺测、抽样、平滑、不确定性和本画像的锁定提交。手工改图若不可避免，要保存可编辑源、逐项改动记录和前后版本，不能让它切断数据到图的链条。

## 可迁移的视觉系统

### 字体与坐标轴

- 采用清爽的无衬线层级、减少上/右边框、弱化非必要网格、使用无边框图例；这些是默认值，不是对每种图的强制模板。
- 字体按最终物理尺寸而不是屏幕截图设定。用含中英文覆盖的 fallback 栈，不假定 Helvetica/Arial 一定存在；导出前检查替换字体、数学符号和负号。
- 数学排版优先使用 Matplotlib 自带能力。LaTeX 只在环境已验证且任务确需时启用，不能作为默认依赖。
- 刻度、轴名、单位和参考线不得为了“干净”而删除。只有对象能被标题、直接标签或图例无歧义识别时，才可隐藏重复的分类刻度。

### 版式与图例

- 多面板共享字体、线宽、颜色语义、单位和小数位；只有量纲与范围可比时才共享轴。
- 大图例可放进独立面板，避免遮挡数据；面板字母、阅读顺序和正文引用必须一致。
- 上游的超宽画布只作为“给密集比较留空间”的启发。实际宽高由目标期刊的单栏/双栏物理尺寸决定；不要先用巨幅画布，再靠缩放制造看不清的文字。
- 自动布局只是起点。最终尺寸下检查裁切、重叠、图例漂移和留白，必要时手工设置网格与边距。

### 配色与冗余编码

- 可借鉴“主方法、改进、对照、中性背景、单一高亮”的稳定语义角色，但不照搬蓝—绿—红的固定含义。
- 分类图优先本仓库登记的 Okabe–Ito/Tol 色板；连续量使用感知均匀的顺序色板；以有意义的中心值为界的正负偏差才使用发散色板。
- 颜色不是唯一通道。线型、点形、纹理、边框或直接标签至少补一个；同一含义跨图锁定同一视觉编码，并做灰度和常见色觉缺陷检查。
- 高亮色只用于少量、预先说明的重点。透明度可以处理遮挡，不能单独承担类别或消融层级。

### 输出与运行

- 批量/无界面环境先使用稳定的非交互后端；输入形状、维度、长度和有限值在绘图前校验，随机布局或抽样固定种子并留记录。
- 主输出优先 PDF/SVG/EPS，另存 PNG 供预览。栅格 DPI 按最终印刷尺寸和内容密度决定，300 DPI 是常见起点；只有细密线条或出版要求确有需要时才提高到 600 DPI。
- 保留可编辑矢量文字时要嵌入或明确字体策略；提交前在另一台机器或干净环境打开文件，检查字体、透明度和裁切。
- 文件名稳定、输出目录明确、脚本重复运行不依赖交互状态；不得把 notebook 的隐藏状态当成唯一绘图环境。

## 图型全覆盖与使用护栏

下表覆盖锁定版本中出现或由其 skill 明确总结的图型家族。它是能力索引，不代表每篇论文都要使用全部图型。

| 图型家族 | 可迁移技巧 | 本地护栏 |
|---|---|---|
| 定量分组柱图 | 组间留白、清晰边框、少量直接数值、统一小数位、图例与面板协调 | 柱图默认从零开始；非零基线只有在科学上必要且显式标轴断裂、理由与影响时才允许。误差与样本单位必须定义 |
| 构成/比例柱图 | 固定类别顺序、纹理或边框区分、图例远离数据 | 声明分母、归一化方法、未知/缺失类别及是否总和为 100%；不要用面积观感替代数值口径 |
| 消融图 | 固定主方法视觉身份、并排比较、必要时直接标值 | 不接受只靠 alpha 深浅表达消融程度；必须加纹理、边框、点形或明确标签，并说明每个变体实际移除了什么 |
| 趋势、学习曲线与时间序列 | 限制同轴曲线数量、稳定线宽、共享图例、必要时使用不确定性带 | 时间/步骤轴要定义；缺测处断线；带状区间必须说明 SD/SE/CI/分位区间、样本数和重采样单位，不能用平滑隐藏波动 |
| 多面板比较 | 统一尺度、面板标题、专用图例区、从左到右的比较叙事 | 不可比较的指标不要强行共轴；逐面板记录数据来源和变换；最终栏宽下逐项视觉复核 |
| 热图/矩阵图 | 明确行列标签、色条标题、必要时少量单元格注释 | 必须声明数据语义、原始/归一化尺度、色板方向、范围与裁剪、中心值、缺测掩膜及色条单位；相关矩阵、概率、计数不能共用含糊的“强度”标签。逐列独立归一化通常会破坏跨列绝对量级的可比性，必须披露公式、零方差/全缺失列处理，并明确颜色只能在列内解释；保留原始矩阵或原始尺度补充表/图 |
| 散点、流形、轨迹与扩散示意 | 密集点降低遮挡、关键轨迹用饱和线和箭头、必要时栅格化点层而保留矢量轴字 | 声明抽样、坐标变换和方向含义；不能只画“好看的子样本”；降维坐标不自动具有物理含义，概念轨迹不得冒充观测轨迹 |
| 雷达/极坐标比较 | 少量系列、统一线宽、在标签处给出明确尺度 | `reference-only`：轴顺序、归一化和面积会改变观感。仅在维度少、同量纲或已合理归一化时使用，并同时提供表格、点图或平行坐标等可核对替代 |
| 3D、球体与几何概念图 | 光照、透明度、箭头和低饱和背景可帮助解释结构 | `reference-only`：透视、遮挡和表面积会制造定量暗示。默认提供 2D 投影；纯概念图必须标“概念示意”，不得从光照或距离读取数值 |
| 概念图、示意图与混合工具成图 | 去除刻度、突出实体和关系、分层安排信息 | 每个实体和箭头都可追溯到论证；标出观测/推断/假说；若有手工或外部软件步骤，保存源文件、许可和操作记录，不声称端到端脚本可复现 |
| teaser/已发表成品图 | 可研究信息层级、留白、视觉叙事和跨面板一致性 | `reference-only`：成品图和论文资产不复制、不作为模板素材包分发；只提炼抽象结构，重新用本项目数据和原创表达实现 |

## adopt / adapt / reject / reference-only 决策

### adopt：直接采用的通用纪律

- 简洁边框、无边框图例、跨面板一致的视觉语义。
- 图例独立面板、稳定阅读顺序、适量留白。
- 柱体清晰边框与纹理、线图有限系列、必要且定义清楚的不确定性带。
- 真实数据驱动、无界面可重跑、矢量优先并保留高质量预览。
- 所有输出在最终物理尺寸下由人实际查看，而不是以“文件存在”代替审查。

### adapt：吸收意图但按任务改造

- 固定字号、固定线宽和超宽画布改为由期刊栏宽、语言、标签密度和阅读介质反推。
- Helvetica/Arial 改为含 CJK 与数学符号的字体 fallback；TeX 改为显式可选。
- 蓝/绿/红语义色改为无障碍色板加冗余通道，并在全文锁定角色。
- 动态收紧 y 轴只用于非柱图，且必须披露范围；柱图维持零基线默认。
- 自动紧凑布局、直接数值标注、300/600 DPI 均按内容和最终尺寸选择，不机械套用。
- 隐藏分类刻度仅在识别信息没有损失时采用；否则保留或直接标注。

### reject：不进入本仓库默认实践

- 只靠透明度或色相区分类别、消融层级或证据强度。
- 为放大差异而截断柱图基线、压缩坐标、隐藏异常值、选择性抽样或连接缺测。
- 默认开启系统 LaTeX、假定特定商业字体存在，或以机器相关配置作为复现前提。
- 在生产脚本中硬编码论文结果、使用示例随机数据冒充真实结果、把漂亮 demo 当作统计证据。
- 复制上游脚本、图像、成品图或长文后用本仓库 MIT 许可再分发。
- 因为某种布局在上游出现过，就忽略目标期刊、无障碍或当前数据的约束。

### reference-only：只研究思路，不默认落地

- 雷达/极坐标、3D 球体、透视几何和纯概念场景。
- 由 Python 与手工排版混合完成的成品、teaser、论文资产及项目特定数据/标签。
- 上游的具体品牌色值、固定巨幅尺寸和论文专用构图；如确需复刻，另做许可与任务适配审查。
