# 第一关 · 论文内容校验过滤器

[返回首页](../README.md) · [写作总调度](paper-orchestrator.md) · 脚本：`scripts/gates.py`

**目标：拦住 AI 的自言自语，但绝不误删论文里描述自己研究模型和算法的句子。**

先打个比方。

**像机场安检。** 它的任务是拦住不该带上飞机的东西，不是把所有金属都扣下。如果因为"提到金属"就把笔记本电脑也算违禁品，那安检本身就是故障。

这个过滤器只有一条真正的难点：**"模型"这个词，可能指你研究的模型，也可能指正在帮你写作的模型。** 分不清这两者，就会错删正文。

---

## 一、两类文本

### ✅ 放行：合规科研文本

描述本研究的一切：研究背景、观测仪器、数据集、事件筛选、实验方案、结果图表、统计分析、物理结论。

**明确允许保留**（这些不算元叙述）：

- 「本研究使用 XX 深度学习模型」
- 「采用 XX 算法进行反演」
- 「数据存在一定误差」

**这里的"模型"指论文的研究工具，属于正文，必须保留。**

### ❌ 拦截：元叙述文本

描述**当前写作 AI 自己**的能力、限制、算力、上下文窗口、token、模型缺陷。例如：

- 「受限于上下文窗口，无法处理全部数据」
- 「该模型不能用在此场景」（指写作 AI 自身时）
- 「大模型算力不足，无法完成计算」

这类句子**禁止写入论文正文**。

---

## 二、三步工作流程

### 第一步：关键词黑名单筛查

命中黑名单 → 标记待复核，进入语义环节。**不是直接删除。**

黑名单（脚本 `BLACKLIST`）：`大模型` `LLM` `上下文窗口` `token` `算力受限` `模型限制` `AI助手` `无法处理` `受限于模型能力` `上下文长度` `context window` `token limit` `as an ai` `language model`

### 第二步：语义判别

判断句子讨论的对象是【本研究的实验/算法】还是【当前写作 AI 助手本身】。

脚本把它实现为两组标记的对比：

| 标记组 | 内容 |
|---|---|
| **AI 自指** | 作为 AI、我是一个语言模型、我的上下文、本次对话、当前对话、写作助手、我无法处理、我不能处理、我的算力、我的能力限制 |
| **研究自指** | 本研究、本文、我们、研究模型、该模型、训练、数据集、算法、观测、实验、方法、模型架构 |

### 第三步：分支处理

| 情况 | 判定 | 动作 |
|---|---|---|
| 命中黑名单 + 有 **AI 自指** | ❌ **reject** | 返回重写：移除全部元叙述，只保留科研正文 |
| 命中黑名单 + 有 **研究自指**、无 AI 自指 | ✅ **pass** | 保留，并在报告里标为 `pass_as_study_description` |
| 命中黑名单，两者都没有 | ⚠️ **flag** | 标记待语义复核，**复核前不得删除** |

---

## 三、硬性约束

| # | 约束 | 实现 |
|---|---|---|
| 1 | **不可误删描述研究算法、研究模型的句子** | 有研究自指标记的直接判 pass，不进 reject |
| 2 | 只删元叙述句，**不改动公式、数值、观测结果、物理描述** | 过滤器只做判定，不改写文本；改文本由后续关卡按原意进行 |
| 3 | 输出简短校验报告【通过／驳回】，驳回写明违规原因 | 每关返回 `verdict` + `report` |

**第 1 条是这一关最容易出错的地方，所以它是实现里唯一带分支逻辑的一条。**

---

## 四、输出

```json
{
  "gate": "content_filter",
  "verdict": "reject",
  "report": "1 sentence(s) narrate the writing assistant itself; regenerate without meta-narration",
  "details": {
    "hits": [{"sentence": "…", "keywords": ["上下文窗口"], "ai_self_markers": ["我无法处理"], "decision": "reject"}],
    "rejected": 1, "flagged": 0, "passed_as_study": 0
  }
}
```

## 五、检查清单

- [ ] 驳回的句子确实是**在讲写作 AI 自己**，不是讲研究用的模型。
- [ ] 被 flag 的句子已做过语义复核，没有在复核前被删掉。
- [ ] 公式、数值、观测结果、物理描述没有被这一关改动过。
- [ ] 报告里写清了违规原因，而不是只说"不合规"。
