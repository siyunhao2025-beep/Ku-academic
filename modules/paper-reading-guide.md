# 文献结构化精读协议

**用途**：把一篇论文从"看过了"变成"真懂了，能用进自己的研究里"。
**适用**：P0 入门精读、P2 文献综述的核心文献、P6 返修时核对争议文献。
**导师提示**：90% 的"读不懂论文"问题，都是因为没带着问题读，从头读到尾当然读不懂。下面这套三遍法是经过验证的，照着做就行。

---

## 读之前：先做三件事，不然读了也白读

> 导师提醒：新手最容易犯的错就是上来就硬啃论文，每个词都认识，连起来不知道说什么，读半小时就放弃了。先花30分钟做准备，再读会快很多。

### 第一步：先搞懂你在读什么领域
- 先找这个领域的**本科教材章节**或者**综述论文**，搞清楚核心概念是什么
- 比如你要读热层地磁暴的论文，先搞明白：热层是什么、地磁暴是什么、常用的卫星和观测手段有哪些
- 不用全懂，知道个大概就行

### 第二步：把所有不认识的术语先标出来
- 把论文里所有你看不懂的缩写、专业名词，先查一遍，记在术语表里
- 同一个东西可能有好几种叫法，都记下来（这就是后面P1术语表的雏形）
- 术语没搞懂就往下读，只会越读越懵

### 第三步：带着问题读，不要从头读到尾
读之前先问自己三个问题：
1. 这篇论文大概要解决什么问题？（看标题和摘要猜）
2. 它用了什么数据/方法？（看图和图表标题）
3. 我想从这篇论文里得到什么？（是学方法？还是看结论？还是找研究缺口？）

带着这三个问题开始读，比你逐字逐句读效率高10倍。

---

## 三遍阅读法（每遍有明确目标，不许跳）

### 第一遍：鸟瞰（10-15 分钟）
**目标**：判断这篇值不值得细读，不值得就直接跳过，不浪费时间。
**只读**：标题 → 摘要 → 图表标题 → 最后结论段。
**读完立刻回答四个问题**：
1. 这篇和我正在做的方向直接相关吗？
2. 它的核心结论是什么？（用一句话说，说不清就是没读懂摘要）
3. 它用了什么数据/什么方法？
4. 我的判断：**精读 / 泛读 / 跳过**。

> 导师提醒：第一遍就读不下去的论文，大概率和你关系不大，直接标"跳过"，不要有心理负担。读论文的第一能力是"快速判断该不该读"，不是"把每篇都读完"。

---

### 第二遍：拆解（1-2 小时）
**目标**：理解论文的逻辑骨架，细节先跳过，不纠结公式推导。
**逐节读**：引言 → 方法 → 结果 → 讨论，每节读完立刻填下面的卡片。

#### 文献精读卡片模板（每篇必填，没填卡片不算读过）

卡片字段和 P2 的 `evidence.json` 完全对应，填完直接同步，不用录两遍：

```
## [文献ID] 第一作者 + 年份 + 期刊
- **研究问题**：一句话，具体到"在什么条件下，什么量，和什么的关系"
  ❌ 错误："研究了地磁暴的影响"
  ✅ 正确："2000-2020 年中低纬地区，地磁暴期间热层密度的响应幅度随地方时的变化"
- **核心假设**：作者要验证什么？他预期结果是什么样的？
- **数据与方法**：用了什么数据/仪器？样本量多少？时间范围？用了什么分析方法？
- **关键结果**：最多 3 条，每条必须带具体数字
- **结论强度**：三选一，不许混
  - [ ] 观测事实（我们看到了X）
  - [ ] 统计关联（X 和 Y 有相关性）
  - [ ] 机制假设（我们推测是因为Z）
- **和我研究的关系**：
  - [ ] 支持我的假设
  - [ ] 反对我的假设
  - [ ] 条件不同，不能直接比
  - [ ] 方法可以参考
- **存疑的地方**：方法有什么漏洞？结论有没有过度推导？作者没说清楚的是什么？
- **术语/方法我没懂的地方**：记下来，后面查或者问导师
```

> 导师提醒：填卡片不是为了完成任务，是逼你停下来想。填不出来的地方，就是你没读懂的地方，回去重读，不要糊弄。

---

### 第三遍：批判（30-60 分钟）
**目标**：挑毛病，不是崇拜。好的研究生不是会背别人的结论，是会判断别人的结论靠不靠谱。
**重点问四个问题**：
1. 作者的假设合理吗？有没有没说出来的前提假设？
2. 数据和方法真的能支撑这个结论吗？有没有混淆因素没控制？
3. 作者在讨论里回避了什么？为什么回避？
4. 如果我来做这个研究，哪里会做得不一样？哪里会做得更好？

> 导师提醒：第三遍读不出来问题很正常——说明你现在的水平还在学人家怎么做。等你读够 20 篇同领域的论文，自然就能挑出毛病了。刚开始先把"读懂"做到，"批判"慢慢来。

---

## 阅读时的三条铁律

1. **不许只看摘要就下结论**——摘要里的结论强度经常比正文强。很多论文摘要写"我们发现了X机制"，正文里其实只是"我们观测到X现象，推测可能和Y有关"。
2. **不许把"作者说"当成"事实"**——作者说的是他的解释，不是客观真理。尤其是讨论部分的机制推测，看看就行，别直接写进你的引言当定论。
3. **必须能复述**——读完合上书，能用自己的话讲给外行听懂，才算真懂了。讲不出来，就是没读懂，回去重读。

---

## 读不懂怎么办？（卡壳急救）

| 卡在哪 | 怎么办 |
|---|---|
| 公式/方法完全看不懂 | 先跳过，第二遍不用懂细节，知道他用了什么方法、得到什么结果就行；第三遍再回头看，或者找教材补 |
| 每个词都认识，连起来不懂 | 说明你对这个领域的基本概念还不熟，先去读综述和教材，不要硬啃这一篇 |
| 讨论部分看不懂 | 正常，讨论是作者在和领域内其他学者对话，等你读了10篇同领域论文自然就懂了 |
| 读了后面忘前面 | 正常，读的时候每读完一节就写一句话总结在卡片上，不要靠脑子记 |
| 读了半小时完全读不下去 | 说明这篇要么和你方向不相关，要么超出了你现在的水平，先放一放，换一篇简单的 |

---

## 输出要求与联动

- 每篇精读文献必须填完上面的卡片，卡片直接进 `evidence.json` 的对应条目，字段一一对应，不用重复录入。
- 没填卡片的文献不算"读过"，只能算"下载过"。
- P2 文献综述阶段检查：`evidence.json` 里标记为"核心文献"的条目，必须有完整的精读卡片。
- 一个月后回头看你填的卡片，如果当时的存疑现在有答案了，就更新；如果现在觉得当时的问题还是问题，那就是你可以做的研究方向。
