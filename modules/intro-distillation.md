# 阶段0 · 导师引言风格蒸馏器

[返回首页](../README.md) · [写作总调度](paper-orchestrator.md) · [期刊语料学习](journal-distillation.md)

**可选模块，只用于引言创作，在压缩流程之前执行。**

**目标：从导师同方向的公开论文里，提炼引言的叙事骨架，生成一个你能直接用的引言写作模板。**

先打个比方。

**像学乐高说明书。** 你不是抄他拼出来的那辆车，你是学**他先拼底盘、再上车顶、最后装轮子**这个顺序。同样几块砖，换个主题照样能拼出别的东西。

**我们要的是这个顺序，不是那辆车。**

---

## 一、硬性约束（先看这条）

> ⚠️ **只学习结构逻辑，禁止复制导师原文句子；输出为写作框架，不输出成品段落。**

这条不是建议。摘抄导师原文会带来两个真实风险：

| 风险 | 说明 |
|---|---|
| **查重** | 同一课题组、同一方向的表述重复，查重系统第一个抓的就是这里 |
| **版权与学术规范** | 未标注来源的成段借用属于学术不端，与是否同组无关 |

**所以本模块的输出里，不允许出现导师论文的原始句子。** 如果要展示某个段落的功能，用**你自己的话**概括它的作用，例如「这一段先给出领域现状的公认结论，再用一个转折把问题顶出来」，而不是引用原句。

---

## 二、触发条件

满足任一即可：

- 用户给出**导师姓名 + 单位**
- 用户上传**导师论文 PDF**
- 用户明确要求"生成我导师风格的引言模板"

---

## 三、执行步骤

### 1. 检索导师同方向公开论文，**只提取引言章节**

检索用可用学术连接器；Crossref 只作元数据后端。**公开论文**——付费墙内容不绕过，拿不到就说明拿不到。

### 2. 逐段拆解

对每一段，记录两件事：

| 项 | 内容 |
|---|---|
| **该段核心主题** | 这一段在讲什么（一句话） |
| **与上一段的递进逻辑** | 为什么上一段之后要接这一段 |

### 3. 提炼"倒三角收敛链路"

引言的标准形状是**从宽到窄**：

```text
领域大背景
   ↓  这个领域里有一个悬而未决的问题
具体问题
   ↓  已有工作做到哪、卡在哪
研究缺口
   ↓  所以本研究做什么
本研究目标与思路
```

拆解时记录：**每个下钻动作是靠什么完成的**（一个公认结论？一个矛盾？一个方法局限？）。这才是可迁移的部分。

### 4. 提炼叙事框架、衔接逻辑、术语习惯、句式风格

- **叙事框架**：几段、每段功能
- **衔接逻辑**：段与段之间用什么方式推进（转折 / 递进 / 由现象到机制）
- **术语习惯**：该方向惯用的名词与缩写
- **句式风格**：长句多还是短句多、主动还是被动、第一人称用不用

⚠️ **风格要描述成规则，不要变成模板句。** 写「偏好用一句短句收束每段」，不要写「每段结尾都用：综上所述，……」

---

## 四、输出（三件）

| # | 输出 | 说明 |
|---|---|---|
| 1 | **导师引言段落逻辑拆解** | 每段核心主题 + 段间递进关系 |
| 2 | **结构化引言写作模板** | 按功能分节：背景段 / 问题段 / 缺口段 / 目标段，每节写明**该写什么**与**不该写什么** |
| 3 | **可直接使用的引言提示词** | 你把研究主题填进去就能用 |

**输出的是写作框架，不是成品段落。** 如果用户要成品，那是阶段1 的事。

---

## 五、用户定稿与存档

```text
5. 用户基于模板撰写引言初稿 → 人工打磨定稿
6. 定稿后的完整引言 → 存入【引言箱（A）】原始存档
```

```bash
python scripts/boxes.py init runs/my-paper
python scripts/boxes.py add runs/my-paper A --text "<定稿引言>" --label "Introduction (final)"
```

> **只有引言完成定稿存入原始存档箱之后，后续压缩流程才会处理引言箱（且仅生成临时压缩副本）。**

**不允许边压缩边创作引言。** 引言定稿是硬前置条件。

---

## 六、与压缩流程的边界

| 阶段 | 引言箱的状态 |
|---|---|
| 阶段0 完成前 | **不存在**，压缩流程不碰它 |
| 阶段0 完成后 | 原始存档**永久不变**；压缩只写独立的副本文件 |
| 阶段3 导出 | 读**原始存档**，不读任何压缩副本 |

- [ ] **输出里没有任何一句导师原文**（这条要逐句核对，不能凭感觉）。
- [ ] 每段都写了核心主题与段间递进逻辑。
- [ ] 倒三角收敛链路被明确画出来了。
- [ ] 风格描述是规则而非模板句。
- [ ] 输出是框架，没有直接生成成品段落。
- [ ] 用户定稿后的引言已入 A 箱原始存档。
- [ ] 未绕过的付费墙内容；拿不到的已如实说明。
