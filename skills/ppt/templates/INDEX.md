# Cherry Studio PPT 模板库 · 51 页场景索引

> 每个模板 = 一个可复用的飞书幻灯片布局 XML（960×540）。
> 用法：按场景选版 → 使用 `scripts/template_fields.py prepare` 生成字段草稿 → 填写真实内容 → `scripts/validate.py` 校验 → 截图与内容检查。详细操作见 [模板准备](../references/template-authoring.md)。模板包含示例内容，不能直接视为完成稿。

## 封面 / 转场 / 封底（P1-P6, P51）

### P01 品牌主视觉开场

- **适用**：低密度开场、主题发布或品牌介绍；替换Logo时保持比例，短签可放时间、主题或行动语。
- **结构**：左侧双行标题、副标题与短签；右侧直接展示真实品牌图，保持原比例，不另加背景框。
- **替换**：使用字段索引更新文字、图片与原生数据；内容长度或统计范围变化后重新校验并检查截图。

### P02 浅底导语与产品图

- **适用**：建立产品印象、展示界面或作品；图片替换后按可用区等比适配，不增添仿造窗口框。
- **结构**：左侧窄幅浅蓝导语区，右侧宽幅原始截图；标题与短说明集中，图片保持真实比例。
- **替换**：使用字段索引更新文字、图片与原生数据；内容长度或统计范围变化后重新校验并检查截图。

### P03 编号章节转场

- **适用**：章节切换与叙事停顿；章序只表示演示结构。
- **结构**：左侧大章节号浅色面，右侧主题标题与说明。
- **替换**：使用字段索引更新文字、图片与原生数据；内容长度或统计范围变化后重新校验并检查截图。

### P04 三项方案支点

- **适用**：三个同层级支点、产品特征或方案模块；每栏保留一段解释和一句归纳，图标与底色按语义统一。
- **结构**：三列无边框浅底；图标与标题并排，正文与价值句靠拢，按实际字数控制卡片高度。
- **替换**：使用字段索引更新文字、图片与原生数据；内容长度或统计范围变化后重新校验并检查截图。

### P05 转场 · 装饰彩点
- **适用**：风格化转场页（需要视觉过渡时）
- **结构**：居中标题 + 副标题 + 珊瑚红短线 + 5 色圆点（品牌色点缀）
- **适合内容**：一个过渡金句
- **示例**："清晰，是一切行动的起点。"
- **替换**：标题/副标题 → 你的过渡语

### P06 行动与联络入口

- **适用**：明确下一步号召、结束邀请或联系入口；联系方式替换为可用信息。
- **结构**：双行动短语与侧边联络区形成不对称构图，短连线建立阅读方向。
- **替换**：使用字段索引更新文字、图片与原生数据；内容长度或统计范围变化后重新校验并检查截图。

### P51 不对称品牌结尾
