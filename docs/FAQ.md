# 常见问题

[返回首页](../README.md) · [新手教程](GETTING_STARTED.md)

### 下载后双击什么？
想在 ChatGPT 使用：不用运行脚本，优先按新手教程安装 Skill 或让 GitHub 连接读取它。本地 Windows 工具可运行 START_WINDOWS.bat；它只准备环境和示例，不会自动写论文。

### 没有 Skills 上传按钮怎么办？
这是账号、工作区或功能可用性的差异。使用已授权的 GitHub 读取方式，或在支持文件解压读取的会话中上传 ZIP。不要把文件上传误报为永久账号安装。

### 为什么仓库叫 Cool-Academic，调用名还是 research-mother？
Cool-Academic 是独立项目名称；research-mother 是保留兼容性的 Skill 标识。安装包顶层目录也叫 research-mother。

### 五个上游 Skill 都安装了吗？
没有这一默认保证。config/upstream.lock.json 登记的是固定来源、版本和入口。scripts/upstream.py 可以隔离下载源码；不会在 GPT 原生安装、执行 hooks 或自动配置密钥。必须分别验收安装和实际调用。

### 需要收费 API 或云服务器吗？
本项目本地脚本不需要模型 API Key，也不要求云服务器；联网检索需要网络。全文阅读与写作使用你当前的 AI 平台，费用、额度与外部连接由该平台及服务决定。本仓库没有代购模型、充值或隐藏上传功能。

### 搜索返回很多条，是否就是找到了新领域论文？
不是。元数据候选仍需相关性筛选、版本核验和全文阅读。当前本地后端是 Crossref，不是所有数据库的集合；单次检索可能截断，也可能漏掉延迟收录文献。失败和零结果须区分。

### 为什么有些 PDF 无法下载或读取？
下载器只访问明确授权的 HTTPS 主机，不绕过登录或付费墙。加密、扫描件或复杂排版可能无法提取可靠文本，应使用授权副本和页面图像检查。提取成功不能自动把 full_text_read 标成 true。

### 20–50 篇论文是否保证学会期刊风格？
不保证。样本需要适合目标期刊和体裁，并覆盖独立作者组；还需留出评测。程序聚合阅读卡不等于 AI 已读懂全文。自然表达的目标是准确、具体、衔接顺畅，不是承诺规避检测或保证录用。

### 不防御性写作是否意味着不写限制？
不是。删除没有贡献的模板化免责声明；保留真正影响方法、解释与复现的限制。明确结果直接写，机制证据不足时精准限定，不把整段都写成自我辩护。

### 为什么 init 成功后还是 needs_inputs？
它只初始化空项目，需要真实材料。quickstart 的 demonstration_only 也只是安装示例；这两种状态都不能当成已完成研究。

### 能否自动每天找论文？
当前默认不启用定时订阅。已提供按次运行的检索工具和提示词；未来定时执行需要另行设置实际调度器，并确认时间、来源与通知方式。

### 私有材料放哪里？
放在本地私有目录或你认可的私有会话。不要提交公开仓库。runs、private、private-corpus 和常见数据格式默认被忽略，但你仍须检查 git status；忽略规则不能撤回已经提交的文件。

### 更新仓库后，需要重新安装吗？
已上传副本不是与 GitHub 实时同步的工作树，应按宿主界面更新。源代码使用者保存本地修改后再 git pull；项目资料应与软件代码分离备份。
