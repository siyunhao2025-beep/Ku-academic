# 验收范围

本地自动化测试核验确定性逻辑：DOI/日期、分页和失败状态、补稿字段与证据等级、作者组泄漏、期刊卡聚合、输入哈希与依赖失效、危险路径、重复片段提示、PDF 空文本和重复文件。

必须另外核验：联网后端真实响应；五个上游源码获取和许可；真实 GPT 账号安装与一次触发；代表性 PDF 的文本/图像阅读；真实目标期刊的逐篇卡片与留出测试；实际研究代码/数据/图表一致性。未做的项目不能因为单元测试通过而标通过。

少 AI 味的检验：随机隐藏作者/处理方式的专家比较、语义保留与数字一致性、篇章组织、专业术语和修辞适配。AI 检测分数不是真实性或科研质量证明。

最新文献检索的验收：已知相关文章能否被找回、时间窗口和版本是否正确、延迟收录是否补捞、相关性筛选是否准确、失败是否可见、元数据是否被误当全文。不得用命中条数直接宣称检索召回率。
