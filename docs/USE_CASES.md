# 直接复制的任务提示词

[返回首页](../README.md) · [先安装或读取 Skill](GETTING_STARTED.md)

这些提示词不自动授予文件、网络、代码或账号权限。开始前，确保模型实际读取了 SKILL.md 和对应模块。把方括号中的内容替换成自己的任务。

## 1. 原创研究：从材料到框架

```text
使用 research-mother，领域包为 example-domain。
研究问题：[你的科学问题]；目标期刊：[名称，可暂不确定]。
读取我上传的文献、代码、数据说明、结果和已有稿件。
先输出证据矩阵和“论点—证据—图表—章节”对应表，再按原创研究路线推进。
方法描述必须对应实际配置与运行记录；未运行的分析标为计划，不写成结果。
```

## 2. 写综述：不要逐篇排摘要

```text
使用 research-mother，写一篇关于[主题]的[叙述性/范围/系统]综述。
先建立检索方案与纳入标准，再阅读全文并提取证据。
按研究问题、方法和适用条件比较结论，形成主题框架，避免逐篇堆摘要。
保留检索时间、筛选理由、原文位置和争议；过程不足时不要称为系统综述。
```

## 3. 检索最近 30 天的论文

```text
使用 research-mother 检索截至今天最近 30 天与[具体问题]相关的新论文。
区分在线发表、纸本出版、预印本版本和数据库收录时间，并补查延迟收录记录。
结合当前可用的多源检索，核验标题、DOI、发表状态和相关性。
输出候选与纳入理由；读到全文后再判断对稿件的贡献，不把元数据当全文证据。
给出覆盖范围、截断或失败情况，不宣称遍历了整个互联网。
```

这是本次检索任务，不会自动设置未来定时订阅。

## 4. 从数十篇 PDF 学习目标期刊

```text
使用 research-mother 学习附件中[目标期刊]的[文章体裁]。
先核验元信息、去除重复版本，按作者组划分学习样本和留出样本。
逐篇读取全文及相关图表，记录已读范围和原文位置；提取成功不等于已读。
提炼标题、摘要、引言推进、结果量化、讨论比较、机制限定和图注职责。
把官方要求、样本中观察到的倾向和研究领域惯例分开记录。
先输出阅读卡与草案风格档案，再用留出论文和我的文本检验，不复制原句。
```

可先用少量论文核对流程，再扩充语料。默认卡片编译器要求至少 20 篇训练论文、至少三个训练作者组和一个独立留出作者组；这是工程下限，不是所有期刊的统计保证，也不是总共上传 20 个 PDF 就够了。不要靠降低阈值把试运行标成正式验证。

## 5. 给文章补证据，不防御性写作

```text
使用 research-mother 阅读我的稿件与新增文献。
每项修改必须说明补上了哪一步论证：比较、方法依据、机制约束、定位或纠错。
给出原句、改句、位置、来源和贡献；没有实质贡献时明确建议不加。
明确观测到的现象直接表达；证据不足的机制只限定对应句子。
保留真正影响解释的限制，不堆泛泛的免责声明，不为了引用数量补句子。
```

## 6. 润色英文，保持物理含义

```text
使用 research-mother 润色以下英文，调用 writing-review 模块及适用的已验证期刊档案。
保留所有数字、单位、仪器名称、外部指标、引用和证据强度。
用具体动词替换空泛名词化表达，改善旧信息到新信息的衔接和句式节奏。
区分观测事实与机制推断；不新增缺乏证据的因果关系，也不把每句话都加 may。
直接给出修订后的英文，下方用中文说明三个关键修改。
```

## 7. 根据代码写 Methods

```text
使用 research-mother 读取实际执行的代码、配置、输入说明和运行日志。
梳理筛选、质量控制、坐标/时间定义、分箱、基线、平滑、统计与不确定度口径。
生成 Methods，并逐条关联代码位置和运行记录。
代码实现与稿件描述不一致时指出差异，不把计划的分析写成已经完成。
```

## 8. 科研绘图与图注

```text
使用 research-mother 基于我提供的真实结果作图。
先核对数据含义、单位、采样、缺测、分组和平滑，以及误差条表示什么。
保留源数据和绘图代码；定量图不能用生成图片代替计算结果。
输出图件、图注和处理记录，检查正文数值与图表一致。
```

## 9. 继续上一次工作或换研究领域

```text
使用 research-mother 读取项目目录的 project.json、domain.json、证据和审计文件。
核对已登记输入是否变化，从有效阶段继续；不要仅靠聊天记忆认定任务完成。
领域改为[新领域]时，独立建立检索词、术语、方法条件和检查清单，
不把上一个项目的基线、指标和结论带入新领域。
```

## 10. 核对引用是否真实、是否支持这句话

```text
使用 research-mother，加载 modules/evidence-integrity.md。
对我提供的稿件逐条检查参考文献。

第一遍查身份：标题、作者、年份、期刊/会议、卷期页、DOI 是否与权威记录一致。
有 DOI 就以 DOI 为主键解析，不要靠题名搜索，也不要凭记忆重打元数据。
给出四态判定：VERIFIED / MISMATCH / UNRESOLVED / RETRACTED。
UNRESOLVED 按可能杜撰处理，不得留在正文。

第二遍查支持：这篇文献是否真的支持它所在的那句话。
给出六类状态：SUPPORTS / PARTIALLY_SUPPORTS / BACKGROUND_ONLY /
CONTRADICTS / DOES_NOT_SUPPORT / CANNOT_VERIFY。
CONTRADICTS 和 DOES_NOT_SUPPORT 是硬阻断，必须删句或改句。
PARTIALLY_SUPPORTS 必须把句子收窄到文献真正覆盖的范围，不是打个勾。
不要因为题名关键词重叠就推断支持关系。

重点检查六类高风险错配：综述当原始实验、关联当因果、模拟当观测、
研究范围/条件不匹配、趋势方向相反、二手来源给精确数字。

再按句子强度核对访问深度（python scripts/access.py check <workspace>）：
背景句元数据即可、方法句至少摘要、定量句和机制句必须全文并定位页/图表；
拿不到全文的只精准卡定量/机制句，可走 Unpaywall 合法获取或显式降级，
背景/方法句不连坐，绝不使用盗版来源。

输出 audit/citation-provenance.json，含 citations、blockers、warnings、to_confirm。
查不了的显式标待确认，写明已查到什么、卡在哪、需要什么。
不要把"无法核实"写成"未发现问题"。
```

## 11. 出科研线路图和原理示意图

```text
使用 research-mother，加载 modules/figures.md，为我这项任务出三张图。

第一张科研线路图：从我拿到的数据到得出的结论，路径要能一眼看懂。
每个形状都必须代表一个具名事物，不允许出现没有含义的彩色方块。
计划版和实际版分开存，投稿前对照检查差异。

第二张原理示意图：先说明选哪种原型（架构/流程/组件/概念/对比/分类/部署）。
重点用视觉方式区分观测、推断、假说三个层级，不要混在一起。
图注里必须写明这是概念示意，不能让人误以为是观测结果。

第三张（如适用）数据图：从真实结果文件出图。
颜色不能单独承载信息，必须配形状、线型或直接标注。
优先用无障碍色板（okabe-ito 等），不要用彩虹色。
写明误差条表示什么、样本量或重采样单位。

最后用中文说明每张图的要素与配色逻辑：为什么这个形状代表这个事物，
为什么选这个颜色，颜色之间靠什么区分。
```

## 12. 降低 AI 痕迹（先保证不改坏科学）

```text
使用 research-mother，加载 modules/deai-writing.md 和 assets/deai-checklist.md，
处理我提供的稿子。

先做证据层，再做语言层，顺序不能反。

证据层先说清楚：数字、单位、有效位数、正负号、置信口径、仪器名、
引用、证据强度词，一个字符都不许改。
如果为了读起来更自信把"suggests"改成"proves"，那不是降 AI，是过度声称。
先跑字符级 diff，逐个人工确认数字没有被动过。

语言层先说明本轮具体的清晰度或论证问题；不存在问题的句子不因长度相近而改写。
拆句、合句或删副词都不是默认动作，必须保持术语、命题、引用与证据强度。

中文表达先查主语、对象、比较项、条件与指代，再决定是否拆句、合句或删重复总结。
套话、排比、标点和加粗只作定位信号，不设跨作者通用配额；无出处归因仍是证据阻断项。
不为检测器分数、句长方差或所谓“噪声预算”改文，所有调整都要能说明清晰度或论证收益。

输出：修订稿 + 五层自查记录（证据完整性 / 文献核验 / 图件 / 语言清晰度与模式复查 / 冷读）。
不承诺通过任何 AI 检测工具，不提供绕过检测的方法。
```

## 13. 投稿前跑一遍阶段闸门

```text
使用 research-mother，加载 docs/PHASE_GATES.md，对我的项目跑一遍阶段闸门。

逐项报告：Gate1 范围检索充分性、Gate2 证据基础充分性、Gate3 设计可执行性、
Gate4 结果可靠性、Gate5 稿件质量评分。
每项给出实测值和通过线，不通过的项目说明卡在哪一条。

同时检查硬条件：UNRESOLVED 引用是否为 0、高风险错配是否为 0、
线路图与示意图是否产出、数据图是否经人工视觉审查、降 AI 自查第一层是否全过。

阈值是工程下限，不是统计保证。如果某项不过，告诉我该回哪个阶段补，
不要用调低阈值的方式让它通过。

最强结论只能说"可进入人工投稿复核"。不要给录用概率，不要保证录用。
```

```text
累计 token（口径 A 写入量 · 方法标签）：<数字>
```

## 23. 跑完整的论文写作流水线

```text
使用 research-mother，加载 modules/paper-orchestrator.md，按四阶段跑。

阶段0（可选）：如果我要写引言，先用 modules/intro-distillation.md
蒸馏导师引言的段落逻辑，只输出框架，禁止复制导师原句。
引言我定稿后再存入引言箱原始存档。
```
