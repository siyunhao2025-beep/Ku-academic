# 直接复制的任务提示词

[返回首页](../README.md) · [先安装或读取 Skill](GETTING_STARTED.md)

这些提示词不自动授予文件、网络、代码或账号权限。开始前，确保模型实际读取了 SKILL.md 和对应模块。把方括号中的内容替换成自己的任务。

## 1. 原创研究：从材料到框架

```text
使用 research-mother，领域包为 space-weather-mlt。
研究问题：[你的科学问题]；目标期刊：[名称，可暂不确定]。
读取我上传的文献、代码、数据说明、结果和已有稿件。
先输出证据矩阵和“论点—证据—图表—章节”对应表，再按原创研究路线推进。
方法描述必须对应实际配置与运行记录；未运行的分析标为计划，不写成结果。
```

## 2. 写综述：不要逐篇排摘要

```text
使用 research-mother，写一篇关于[主题]的[叙述性/范围/系统]综述。
先建立检索方案与纳入标准，再阅读全文并提取证据。
按研究问题、方法和适用条件比较结论，形成主题框架，避免逐篇堆摘要。
保留检索时间、筛选理由、原文位置和争议；过程不足时不要称为系统综述。
```

## 3. 检索最近 30 天的论文

```text
使用 research-mother 检索截至今天最近 30 天与[具体问题]相关的新论文。
区分在线发表、纸本出版、预印本版本和数据库收录时间，并补查延迟收录记录。
结合当前可用的多源检索，核验标题、DOI、发表状态和相关性。
输出候选与纳入理由；读到全文后再判断对稿件的贡献，不把元数据当全文证据。
给出覆盖范围、截断或失败情况，不宣称遍历了整个互联网。
```

这是本次检索任务，不会自动设置未来定时订阅。

## 4. 从数十篇 PDF 学习目标期刊

```text
使用 research-mother 学习附件中[目标期刊]的[文章体裁]。
先核验元信息、去除重复版本，按作者组划分学习样本和留出样本。
逐篇读取全文及相关图表，记录已读范围和原文位置；提取成功不等于已读。
提炼标题、摘要、引言推进、结果量化、讨论比较、机制限定和图注职责。
把官方要求、样本中观察到的倾向和研究领域惯例分开记录。
先输出阅读卡与草案风格档案，再用留出论文和我的文本检验，不复制原句。
```

可先用少量论文核对流程，再扩充语料。默认卡片编译器要求至少 20 篇训练论文、至少三个训练作者组和一个独立留出作者组；这是工程下限，不是所有期刊的统计保证，也不是总共上传 20 个 PDF 就够了。不要靠降低阈值把试运行标成正式验证。

## 5. 给文章补证据，不防御性写作

```text
使用 research-mother 阅读我的稿件与新增文献。
每项修改必须说明补上了哪一步论证：比较、方法依据、机制约束、定位或纠错。
给出原句、改句、位置、来源和贡献；没有实质贡献时明确建议不加。
明确观测到的现象直接表达；证据不足的机制只限定对应句子。
保留真正影响解释的限制，不堆泛泛的免责声明，不为了引用数量补句子。
```

## 6. 润色英文，保持物理含义

```text
使用 research-mother 润色以下英文，调用 writing-review 模块及适用的已验证期刊档案。
保留所有数字、单位、仪器名称、地磁指数、引用和证据强度。
用具体动词替换空泛名词化表达，改善旧信息到新信息的衔接和句式节奏。
区分观测事实与机制推断；不新增缺乏证据的因果关系，也不把每句话都加 may。
直接给出修订后的英文，下方用中文说明三个关键修改。
```

## 7. 根据代码写 Methods

```text
使用 research-mother 读取实际执行的代码、配置、输入说明和运行日志。
梳理筛选、质量控制、坐标/时间定义、分箱、基线、平滑、统计与不确定度口径。
生成 Methods，并逐条关联代码位置和运行记录。
代码实现与稿件描述不一致时指出差异，不把计划的分析写成已经完成。
```

## 8. 科研绘图与图注

```text
使用 research-mother 基于我提供的真实结果作图。
先核对数据含义、单位、采样、缺测、分组和平滑，以及误差条表示什么。
保留源数据和绘图代码；定量图不能用生成图片代替计算结果。
输出图件、图注和处理记录，检查正文数值与图表一致。
```

## 9. 继续上一次工作或换研究领域

```text
使用 research-mother 读取项目目录的 project.json、domain.json、证据和审计文件。
核对已登记输入是否变化，从有效阶段继续；不要仅靠聊天记忆认定任务完成。
领域改为[新领域]时，独立建立检索词、术语、方法条件和检查清单，
不把 MLT 项目的基线、指标和结论带入新领域。
```
