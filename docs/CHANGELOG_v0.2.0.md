### 1.2 四条关键判断

**判断一：没有现成仓库把四件事做全。**

引用真实存在、引用确实支持这句话、数字不可被语言修改、部分通过不等于通过——四件事同时做全的仓库，本次检索没有找到。最接近的是 `Maisuria`（前两件做得好）与用户既有 `math-modeling-to-sci`（后两件做得好）。因此 `modules/evidence-integrity.md` 采用**两者融合**：四态身份判定来自前者，六类支持状态与高风险错配清单来自后者。

**判断二：阈值只能当工程下限。**

`lishix520` 的阶段阈值好用在逼人停下来，风险在于把取样下限当成科学充分性。本项目所有阈值统一标注为**可配置工程下限**，并明确禁止用"调低阈值重跑一遍"把试运行标成正式验证。

**判断三：降 AI 必须防止改坏科学。**

这是本轮最有价值的单条结论。降 AI 模块的第一条不是"怎么改得像人"，而是"什么不许动"：数字、单位、符号、有效位数、置信口径、仪器名、引用、证据强度。同时保留一个反直觉的结论——**只删副词而不重组句式，AI 分数反而会变差**。

**判断四：示意图与数据图是两类规则。**

`zLanqing` 回答"怎么把机制讲清楚"，`Maisuria` 回答"怎么让数据可安全辨认"。两者不能合并成一句"图要画好"，因此在 `modules/figures.md` 内部分两节，各给独立检查清单。

| 内容 | 为什么不吸收 |

### 2.6 顺带修掉的真实缺陷（Windows 符号链接）

跑测试时发现 `test_symlink_escape` 失败。**关键判断：这不是本次改动引入的回归** —— 在从 codeload 下载、未经任何修改的原始仓库上单独跑这一项，得到完全相同的失败。

**根因（已用实验确证）：** Windows 创建符号链接需要 `SeCreateSymbolicLinkPrivilege`（管理员权限或开发者模式）。无此权限时，`Path.symlink_to()` **不报错、返回 `None`，但不创建任何东西**。实测证据：

| 探测项 | 结果 |
|---|---|
| `os.listdir(root)` 创建后 | `[]`（空） |
| `os.path.lexists(link)` | `False` |
| `os.lstat(link)` | 抛 `FileNotFoundError` |
| `Path.is_symlink()` | `False` |
| `cmd /c dir /a` | 目录真的是空的（只有 `.` 和 `..`） |

因此测试里那个"用于逃逸"的链接根本不存在，`safe_path` 当然不会抛 `ValueError`。

**处置（两处）：**

1. `scripts/research.py::safe_path` —— 原实现只在最后对整条路径 `resolve()` 一次，Windows 上无法拦住中间组件为 reparse point 的情况。改为**逐组件**推进：每个组件先 `resolve()`，再比对是否仍在 `root` 内，越界立即抛错。
2. `tests/test_research.py` —— 加 `_can_create_symlink()` 真实探测（建链接后回读确认 `is_symlink() and exists()`），用 `@unittest.skipUnless` 诚实 skip；同时新增 `test_symlink_escape_when_link_not_creatable`，用 `../secret` 和 `a/../../secret` 覆盖不依赖符号链接的穿越路径。

**这个修正的意义：** 原测试在本机会因环境原因失败，掩盖真实信号；修完之后测试矩阵在本机是可信的。而 `safe_path` 的逐组件检查是实打实的安全加固——即使在支持符号链接的平台上，也比原来的单次 `resolve()` 更严格。

## 四、降 AI 率策略（需求 #6 的逐项对照）

### 4.1 第一层：什么不许动（先做这层）

| 不许动 | 说明 |
|---|---|
| 数字、单位、符号、有效位数 | 3.14 不能成 3.1；1.20 不能成 1.2 |
| 置信口径 | SD / SE / CI / 显著性水平，及样本单位 |
| 仪器与产品名 | 型号、数据集版本、坐标系统名 |
| 引用 | 位置与编号 |
| 证据强度 | `suggest` / `indicate` / `demonstrate` / `is consistent with` 的层级 |

**反过度纠正**：为读起来更自信把 `suggests` 改成 `proves`，是制造过度声称，不是降 AI。同理不允许把被动语态一律改主动、把 `we` 一律删掉、把术语换成通俗说法。

**判定口诀**：如果一个改动让结论看起来更强，但没有新证据支持这个增强，就不能改。

### 4.2 第二层：句式节奏（主力手段）

| 指标 | 人类写作 | AI 典型 |
|---|---|---|
| 句子词数范围 | 12–55 词 | 集中 15–25 词 |
| 句长标准差 | 10–15 | 常 <5 |

- **单项收益最大**：重组句式节奏贡献约九成可改善空间。
- **反直觉结论**：只删副词而不重组，AI 分数反而变差（logit 恶化约 +0.72）。
- **中文等价判断**：看逗号节律、段落长度、句号密度；出声读一遍。

### 4.3 第三层：中文硬约束

| 项目 | 上限 |
|---|---|
| 每段 AI 高频词 | ≤ 2 |
| 段末总结套话（全文） | ≤ 1 |
| 三元排比（每段） | ≤ 1 |
| 加粗（全文） | ≤ 5 |
| 模糊结尾 | 0 |
| 无出处归因 | 0 |
| 同段破折号 | < 4 |

**噪声预算**：每千字保留 2–3 处轻度 AI 特征。全清干净会变成另一种整齐，同样可疑。

### 4.4 第四层：结构与用词

要拆的：机械排比、均匀句长、空泛名词化、三段式套话、万能过渡、抬头式开场、结尾升华、对称收尾。

要加的：长短句交替、具体化、强动词、与最强对手比较先行、区间优先、信息位置正确。

### 4.5 第五层：交付前自查（强制）

`assets/deai-checklist.md` 五层 55 项，顺序不可颠倒（先证据，后语言）：

1. 证据完整性 12 项 —— 含字符级 diff 核对数字
2. 文献核验 13 项
3. 图件 12 项
4. 语言节奏 13 项
5. 冷读 5 项

**判定**：第一层任何一条未过 → 不得交付。第二层有硬阻断未清 → 不得交付。第三层第 26、27、37 条任一未过 → 不得交付。

### 4.6 边界

不承诺通过任何 AI 检测工具；不提供绕过检测的方法；不隐藏必要的 AI 使用声明；不用生成式工具重写科学结论。

## 五、面向使用者的通俗使用指南

### 5.1 这个 Skill 是干什么的

它是一个科研流程助手，管六件事：想清楚要研究什么、把前人的东西摊开来比、设计怎么做、真的动手做、画图写文章、收尾投稿和返修。

它**不会**替你产生研究结果，也**不会**编造文献。

### 5.2 你不需要知道内部结构

你只要把材料丢给它，说一句"帮我看看"。它会自己判断该走哪一步。

每次回复的最后，它都会给你两行：

```text
下一步建议：<接下来做什么>
你可以直接发送：<一段可以直接粘贴的话>
```

你照着粘贴就行。

### 5.3 六步走完一项研究

**第一步：说清楚要研究什么。** 你给它一个方向，它帮你压成一个能回答的问题，顺手查查别人做过没有。

**第二步：把前人的东西摊开。** 它检索、筛选、核对每篇文献的出处，然后把所有文献的条件和结论列成一张大表来比。这一步会明确告诉你：哪些文献是真的、哪些它查不到（会标成"待确认"，不会假装查过了）。

**第三步：写下怎么做。** 它问你数据从哪来、有哪些限制，然后把每一个参数、每一个对照条件都写下来，还要提前想好"如果我猜错了会怎样"。

**第四步：真的动手。** 它跑你的代码、记下每一步。**跑失败也记下来**——这一步是为了防止只报好看的结果。

**第五步：画图、写文章。** 出三张图：一张说明你干了什么（线路图），一张说明这件事为什么这样发生（原理示意图），一批画你的真实数字（数据图）。然后把文章各部分写出来。

**第六步：收尾。** 写结论（包括明确写出"这个研究没回答什么"）、核对所有引用、投稿、以及审稿意见回来之后逐条回应。

### 5.4 三件它一定会做的事

1. **每个研究任务都出线路图和原理示意图**，并告诉你为什么这么配色、每个形状代表什么。
2. **每条引用都过两道检**：先查这篇文献真不真，再查它是不是真的支持你说的那句话。这两件事它分开查，不混着。
3. **交付前跑一遍自查表**，先查数字有没有被改动，再查读起来像不像人写的。

### 5.5 三件它一定不会做的事

1. **不会编造文献。** 查不到就标"待确认"，写明卡在哪。
2. **不会为了好看改数字或改结论强度。** 把"表明"改成"证明"这种事，它会拒绝。
3. **不会给你录用概率，也不会保证录用。** 它能给的最强结论是"可进入人工投稿复核"。

### 5.6 常见问题

**Q：我只有几篇文献，能用吗？**
能。它会先做能做的部分，把缺的列出来。不会因为材料少就拒绝干活，也不会因为材料少就编东西补上。

**Q：我不懂技术术语怎么办？**
不用懂。它默认用大白话说。你说"继续""下一步""就这么做"，它就往前走。

**Q：它能帮我把稿子的 AI 味去掉吗？**
能，但有个前提：数字、单位、结论强度一个都不动。它改的是说话方式和句子节奏，不是数据。

**Q：它能保证我的稿子通过 AI 检测吗？**
不能，也不承诺。检测分数不是质量标准。它保证的是：表达更准确、节奏更像人写的、科学内容没被改坏。

**Q：审稿意见有一条我不同意，怎么办？**
照实回应，给出理由和证据。它不会帮你假装同意，也不会帮你回避。

**Q：图一定要出三张吗？**
线路图和数据图基本都要。原理示意图如果这项研究确实不需要，可以在图注里说明为什么不需要——但不要硬凑一张充数。

### 5.7 如果你只想快速试一下

复制这句话：

```text
使用 research-mother，领域包用 example-domain。
读取我上传的材料，先告诉我你能做哪些、缺什么。
然后从第一步开始，一次只推进一步，每步结束告诉我下一步做什么。
```
